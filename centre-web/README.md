# Centre Web

React/Vite frontend for EPIC.centre. It provides the launchpad, access request pages, admin user/access management, and application URL/SSL views.

## Local Setup

```bash
cp sample.env .env
npm install
npm run dev
```

Vite usually serves the app at `http://localhost:5173`.

Set `VITE_API_URL` to the API base URL without `/api`, for example:

```text
VITE_API_URL=http://localhost:5000
```

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Run TypeScript build and Vite production build |
| `npm run lint` | Run ESLint |
| `npm run preview` | Preview the production build locally |

Cypress dependencies and support files exist, but `package.json` currently does not define Cypress scripts and no root Cypress config is committed.

## Runtime Configuration

The app reads config from `window._env_` in deployed environments and `import.meta.env` locally. The OpenShift `config.js` is generated by `deployment/charts/centre-web/templates/configmap.yaml`.

Common values:

| Variable | Purpose |
| --- | --- |
| `VITE_API_URL` | Centre API host, without `/api` |
| `VITE_APP_URL` | Public web URL for OIDC redirects |
| `VITE_OIDC_AUTHORITY` | OIDC authority URL |
| `VITE_CLIENT_ID` | OIDC client ID |
| `VITE_DOCUMENT_SEARCH_URL` | Document Search URL |
| `VITE_AI_SEARCH_URL` | AI search URL |
| `VITE_INTRANET_HUB_URL` | Launchpad support/intranet link |

## Main Routes

| Route | Purpose |
| --- | --- |
| `/launchpad` | EPIC application launchpad |
| `/request-access` | Self-service access request catalog |
| `/request-access/auth` | Admin request and user management |
| `/request-access/auth/users/$username` | User-specific access management |
| `/application-urls` | Application URL and SSL tracking |
